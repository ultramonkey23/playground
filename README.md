# 🧪 Ultramonkeydog Playground

**Public research, executable experiments, persistent AI notes, and cross-agent collaboration.**

This is an **internet-accessible, GitHub-backed workspace** for ChatGPT mobile and other authorized clients. It is **not** an inbound tunnel, privileged endpoint, or substitute decision-maker for the private Ultramonkeydog Lab.

**Active branch: [master](https://github.com/ultramonkey23/Bone-bracket/tree/master).** The legacy repository name is `Bone-bracket`; a GitHub Settings rename to `playground` and default-branch change to `master` are still needed. The bootstrap-only `main` branch is not the working branch.

## Do something now, from your phone

- **ChatGPT with GitHub tools:** “Inspect `ultramonkey23/Bone-bracket` on `master`, read `AGENTS.md`, create an issue or perform a bounded experiment, run it with available tools, and verify GitHub readback. Report actual proof limits.”
- **GitHub mobile or web:** [Create an issue](https://github.com/ultramonkey23/Bone-bracket/issues/new/choose) (note, research challenge, experiment). Public contributors can also fork and propose pull requests; they cannot assume direct write permission.
- **Offline/local terminal:** `python3 experiments/001_evidence_integrity/demo.py`; `python3 -m unittest discover -s tools -p 'test_*.py'`.
- **Mobile composer:** [site/index.html](site/index.html) contains a standalone, no-server proposal composer; GitHub Pages is not enabled automatically.

## Operating rules

1. **No private material** without explicit clearance. Do not publish private Lab source, tokens, internal addresses, unreleased game assets, or personal data.
2. **Use live tools over confident prose.** Claims distinguish intention, committed code, actually executed tests, externally observed outcome, and later learning.
3. **One working branch:** direct commits to `master` where authorized, except where GitHub requires a pull request for outside contributors. Avoid rewriting history.
4. **Inspect before creating duplicate systems.** The private Lab already has GitHub, companion intake, research, and worker owners. Never claim public notes have been ingested or learned without observing the actual consumer.
5. **Do not execute untrusted contributions with private credentials.** Keep local reproduction isolated. GitHub CI is optional, not authority over real Lab execution.
6. **No perpetual agency claim.** Chat sessions and GitHub commits are durable artifacts, not persistent autonomous workers.

**Proof of operation:** the connected session initialized the previously empty repository, created `master`, and performed an actual GitHub write/readback. Experiment code and proof should be assessed separately; see [proof map](docs/PROOF_AND_BOUNDARIES.md).
